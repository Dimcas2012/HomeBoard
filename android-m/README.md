# HomeBoard Camera M (Android 6.0+)

Окремий APK для **Android 6.0 Marshmallow (API 23)** і новіших.

- applicationId: `online.secboard.homeboard.m`
- minSdk: 23
- сервер: `https://homeboard.secboard.online`

## Збірка

```bash
cd android-m
.\gradlew.bat :app:assembleDebug
```

APK: `android-m/dist/HomeBoard-Camera-M-debug.apk`
